# BTC tick feature build

The local Binance USD-M aggregate-trade archives were streamed into a compact, ignored 5-second
feature cache. Raw ZIP files remain under `/home/ldtdev/qt/mmtick/data/history_btc_tick`; no raw
market data is committed here.

The manifest records the exact source archive selection, coverage, row count, trade count, output
size, and SHA-256. The generated cache currently contains:

- `1,484,748,340` aggregate trades
- `17,070,981` five-second bars
- `2024-01-01T00:00:00.038Z` through `2026-09-14T23:59:59.997Z`
- OHLC, total/buy/sell notional, total/buy/sell trade counts

The cache is a data-preparation artifact, not a strategy result. Labels, model fitting, and
execution evaluation must still use chronological train/validation/holdout splits and the C++
paper ledger.

Generated by `scripts/build_btc_tick_features.py`; see `manifest.json` for the exact hash and
local output path.
