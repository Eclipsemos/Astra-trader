# BTC raw aggregate-trade baseline OOS

This is the diagnostic baseline for the next BTC/Laya stage. It trains a class-weighted softmax
model on the same raw aggregate-trade samples used by the Laya experiment, then sends the model's
decision tapes through the production C++ `PaperExchange` and fixed-point ledger.

## Results

| Split | Directional actions | Base return | Base PF | Base fills | Stress return | Stress PF | Stress fills |
|---|---:|---:|---:|---:|---:|---:|---:|
| development_train | 1,633 | -1.1247% | 1.156 | 496 | -9.6187% | 0.990 | 496 |
| development_validation | 1,258 | -6.4758% | 0.974 | 571 | -17.0336% | 0.797 | 571 |
| holdout_2026 | 2,138 | -5.9532% | 1.022 | 922 | -17.8271% | 0.844 | 922 |

Validation selected a probability threshold of `0.34` from a small pre-declared grid. The selected
threshold creates actual decisions, so the result is not the same failure mode as the Laya head-only
experiment, which produced only holds. It still fails the economic gate after realistic costs.

## Protocol

- Features: `ret_1m`, `ret_5m`, `ret_15m`, `ret_60m`, `vol_60m`, `flow_5m`, `trades_5m`, `spread_proxy`.
- Labels: 60-minute forward close proxy after 12 bps round-trip cost plus 2 bps safety margin.
- Training: 2025-01-01 through 2025-06-30; standardization uses training rows only.
- Calibration: 2025-07-01 through 2025-12-31.
- Holdout: 2026-01-01 through 2026-08-31.
- C++ costs: base 5 bps fee + 1 bp slippage; stress 10 bps fee + 5 bps slippage.
- C++ tape probability gate: `0`; the model threshold is applied when the tape is generated.

## Decision

Reject this baseline for paper trading. The features carry some classification information, but the
walk-forward C++ replay loses money in both validation and 2026 holdout. The next research step is
to diagnose the label horizon/cost boundary and feature normalization, then compare a revised label
against this frozen baseline before doing deeper Laya fine-tuning.
